# 홈페이지 콘텐츠 제출 요청서

홈페이지에 **실제로 넣을 글과 사진**만 정리했습니다.  
지금 화면에 보이는 내용은 전부 **임시(샘플)** 이며, 아래 항목을 확정본으로 보내 주세요.

---

## 보내는 방법

1. 이 문서(Word·한글·PDF) **「회신」**란에 적거나, 메뉴별 폴더에 파일을 넣어 전달  
2. **한국어 + 영어** 모두 작성
3. 사진은 **원본 파일**(PNG·JPG). 파일명은 용도를 알 수 있게 (예: `로고.png`, `히어로1.jpg`)

4. 각 항목 **· 화면:** — 홈페이지에서 해당 내용이 보이는 위치

**우선순위** · ① 연락처·주소·지도 → ② 로고 → ③ 메인 → ④ 회사소개 → ⑤ 기술·경영

---

### 페이지·메뉴 목록 – 참고자료

홈페이지 구조도 (한글 15p / 영문 15p – 한글/영문 구조는 동일하고 내용 언어만 다름)

```
홈페이지
│
├─ 메인 (첫 화면, 주소만 / 또는 /ko )
│
├─ 회사소개
│   ├─ CEO 인사말
│   ├─ 회사개요
│   ├─ 연혁
│   ├─ 조직도
│   ├─ 인증현황
│   └─ 찾아오시는 길
│
├─ 기술소개
│   ├─ 스마트 제어 시스템(예시)
│   └─ IoT 플랫폼(예시)
│
├─ 경영방침
│   ├─ 경영방침
│   ├─ 윤리경영
│   └─ ESG 경영
│
└─ 홍보센터
    └─ 뉴스&공지
```

위 페이지에서 추가하고자 하는 페이지가 있으면 **추가한 뒤 "-추가" 표시** 한다.
위 페이지에서 삭제하고자 하는 페이지가 있으면 **페이지 옆에 "-삭제" 표시** 한다.

아래 내용을 채울 때 삭제할 페이지는 채우지 않아도 되며, 추가할 페이지는 그에 맞는 컨텐츠를 제공한다.

Ex)
├─ 기술소개
│   ├─ 스마트 제어 시스템(예시)
│   ├─ IoT 플랫폼(예시)
│   └─ 새로 추가할 기술명 - 추가
│
├─ 경영방침
│   ├─ 경영방침
│   ├─ 윤리경영
│   └─ ESG 경영 - 삭제
