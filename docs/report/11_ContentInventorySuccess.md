# 홈페이지 콘텐츠 제출 요청서
작성자: 우해인

홈페이지에 **실제로 넣을 글과 사진**만 정리했습니다.  
지금 화면에 보이는 내용은 전부 **임시(샘플)** 이며, 아래 항목을 확정본으로 보내 주세요.


## 보내는 방법

1. 이 문서(Word·한글·PDF) **「회신」**란에 적거나, 메뉴별 폴더에 파일을 넣어 전달  
2. **한국어 + 영어** 모두 작성
3. 사진은 **원본 파일**(PNG·JPG). 파일명은 용도를 알 수 있게 (예: `로고.png`, `히어로1.jpg`)
4. 아래 주요 요청사항은 각 항목을 **· 화면:**명으로 표기됨. — 홈페이지에서 해당 내용이 보이는 위치

**우선순위** · ① 연락처·주소·지도 → ② 로고 → ③ 메인 → ④ 회사소개 → ⑤ 기술·경영
